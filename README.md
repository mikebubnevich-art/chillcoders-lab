# Budget-Aware Coding Agent

Харнесс для соревнования по решению набора задач в условиях общего бюджета токенов. Сначала агент запускает локальные солверы без LLM, затем оценивает оставшиеся задачи и направляет бюджет на наиболее перспективные. Запросы к моделям идут только через прокси организаторов.

Подробности реализации, формата задач и тестов описаны в [project/README.md](project/README.md).

## Сборка и запуск

Нужны Docker и каталог задач. `TASKS` указывает на каталог задач на хосте, `OUT` — на каталог результатов. Ключ и URL прокси передаются через environment и не хранятся в репозитории.

```bash
: "${TASKS:?Укажите путь к каталогу задач в TASKS}"
: "${OUT:?Укажите каталог результатов в OUT}"
: "${LLM_BASE_URL:?Укажите адрес прокси в LLM_BASE_URL}"
: "${LLM_API_KEY:?Передайте ключ прокси в LLM_API_KEY}"

mkdir -p "$OUT"
chmod 777 "$OUT"
docker build -t hack:latest ./project

timeout -k 1000s 1h docker run --rm --name "run-${TEAM:-local}" \
  --network hack-net \
  -e LLM_BASE_URL -e LLM_API_KEY \
  -e BUDGET="${BUDGET:-100000}" \
  -e TASKS=/data/tasks -e OUT=/data/out \
  -v "$TASKS:/data/tasks:rw" \
  -v "$OUT:/data/out:rw" \
  --read-only --tmpfs /tmp:rw,size=2g -e HOME=/tmp \
  --cap-drop ALL --security-opt no-new-privileges \
  --cpus 4 --memory 16g --pids-limit 512 \
  --workdir /app --entrypoint python \
  hack:latest /app/run_agent.py --tasks-dir /data/tasks
```

Если сеть `hack-net` не создана для локального запуска, уберите `--network hack-net`. Проверяющие передают собственные `LLM_BASE_URL` и `LLM_API_KEY`. `BUDGET` может отличаться от `100000`; если он не задан, используется `100000`.

После каждого решённого задания агент сохраняет `answer.txt` в каталоге задачи и обновляет `$OUT/solutions.json`. В команде выше хостовый каталог `OUT` смонтирован в `/data/out` внутри контейнера.

## Оценка бюджета и выполнимости

Бюджет выражен в выходных токенах: стоимость запроса считается как выходные токены плюс токены рассуждений плюс одна десятая входных токенов. Кеш провайдера не вычитается. Перед каждым запросом резервируется максимальная возможная стоимость; общий потокобезопасный лимитер не даёт параллельным задачам превысить бюджет. Внутренний лимит оставляет запас 3% на расхождения округления прокси.

До вызова LLM локальные солверы бесплатно решают знакомые математические, табличные, поисковые, shell- и кодовые задачи. Проверка выполнимости отбрасывает без расхода токенов задачи с отсутствующими входными файлами, требованием внешнего интернета или пустой инструкцией. В неизвестных случаях агент не угадывает, а передаёт задачу планировщику. Он ранжирует задачи по ожидаемой успешности, награде и оценке стоимости и допускает новые задачи только в пределах оставшегося бюджета.

Для подходящих математических, табличных и поисковых задач модель может вернуть компактный JSON-план, который проверяется и выполняется локально. Если план некорректен или недостаточен, используется обычный LLM-режим. Для задач программирования доступны точечные исправления с проверкой исходными тестами и резервный режим с полным скриптом. `expected` и `check` из `task.json` агенту не передаются.

## Траектории и проверки

`TRAJ` задаёт путь к JSONL-файлу с телеметрией запросов и результатами задач; по умолчанию используется `/tmp/trajectories.jsonl`. Чтобы сохранить траекторию после завершения контейнера, добавьте `-e TRAJ=/data/out/trajectories.jsonl`. Записи не содержат API-ключа.

Проверки без реального LLM:

```bash
cd project
python -m unittest discover -s tests -p 'test_*.py'
python tests/e2e.py
```

## Воспроизводимость

- Базовый Python-образ и версии зависимостей зафиксированы в [project/Dockerfile](project/Dockerfile) и [project/requirements.txt](project/requirements.txt).
- Локальные веса моделей не загружаются; LLM доступна только через заданный прокси.
- Сборка выполняется командой `docker build -t hack:latest ./project`; образ должен быть меньше 4 ГБ. Фактический размер можно проверить командой `docker images --format '{{.Repository}}:{{.Tag}} -> {{.Size}}'`.
- Не добавляйте ключи API в файлы репозитория: они передаются только через переменные окружения.
